## 3. Collector 改动

### 3.1 新增: `projects/collector/classifier.ts` 🆕

**职责**: 每个链上事件入库前，根据合约地址和 event signature 自动打分类标签。

```typescript
// classifier.ts 设计
interface ClassifierRule {
  chain: string;
  contractAddress: string;    // 已知协议合约地址
  eventSignature: string;     // keccak256 event signature
  categoryId: string;
  labelId: string;
}

// 从配置文件读取规则表（已知协议地址 → 分类映射）
const RULES_FILE = getEnv("CLASSIFIER_RULES", "classifier-rules.json");

export function classify(event: {
  chain: string;
  address: string;
  topics: string[];
}): { categoryId: string; labelId: string } {
  const rules: ClassifierRule[] = JSON.parse(fs.readFileSync(RULES_FILE, "utf8"));
  for (const rule of rules) {
    if (
      rule.chain === event.chain &&
      rule.contractAddress.toLowerCase() === event.address.toLowerCase() &&
      event.topics.includes(rule.eventSignature)
    ) {
      return { categoryId: rule.categoryId, labelId: rule.labelId };
    }
  }
  // 兜底分类
  return { categoryId: "other", labelId: "unknown" };
}
```

### 3.2 修改: `projects/collector/src/index.ts`

在事件写入前调用 classifier：

### 4.2 新增 tool: `dc_categories`

```typescript
const dcCategories = {
  name: "dc_categories",
  description: "列出 Data Center 支持的事件分类和协议标签，用于 dc_events 查询时选择 category/label 参数",
  schema: {
    chain: z.string().optional().describe("按链过滤（可选）"),
  },
  handler: async ({ chain }) => {
    const q = chain ? `?chain=${encodeURIComponent(chain)}` : "";
    const data = await dcGet(`/api/v3/data/categories${q}`);
    return formatContent(data);
  },
};
```

## 5. DC API v3 新增端点

**文件**: `projects/dc/v3/`

| 端点 | 文件 | 说明 |
|------|------|------|
| `GET /api/v3/data/categories` | `categories.ts` | 返回分类+标签列表 |
| `GET /api/v3/data/events` | `events.ts` | 支持 category/label 过滤 |
| `GET /api/v3/data/events/:txHash` | `events.ts` | 单笔解码 |
| `GET /api/v3/data/balance` | `balance.ts` | 多链余额聚合 |
| `GET /api/v3/data/token/:address` | `balance.ts` | 代币详情 |
| `GET /api/v3/data/stats` | `balance.ts` | 24h 聚合统计 |

**v2 旧端点保留，v3 新端点并行提供**。
