📦 SDK — TypeScript Client

Integrate InfraX into your app with one import

⚡

Install

npm install @infrax/sdk
TypeScript-first · Tree-shakeable · 0 deps
🛠

Usage

import { InfraX } from '@infrax/sdk';

const infrax = new InfraX({
  baseUrl: 'https://infrax.0xainet.top',
  apiKey:  process.env.INFRAX_KEY
});

// Wallet, Vault, MPC, DC, Payments — all via one client
const wallets = await infrax.wallet.list();
const tx     = await infrax.vault.propose({...});
const events = await infrax.dc.subscribe({...});
🔗

API Reference

infrax.wallet.create() — Create a wallet
infrax.wallet.sign() — Sign a transaction
infrax.vault.propose() — Propose a Safe tx
infrax.vault.approve() — Approve threshold
infrax.dc.subscribe() — Subscribe to events
infrax.dc.query() — Query on-chain data
infrax.mpc.register() — Register key share
infrax.mpc.sign() — Coordinated signing
infrax.payment.checkout() — Subscribe (Stripe fiat)
